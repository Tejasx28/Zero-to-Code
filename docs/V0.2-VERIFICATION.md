## Limits

No two-day human retention experiment has yet occurred. The delayed boundary was tested using explicit timestamps. Questions are prototype measures rather than calibrated tests. Behavior tests cannot prove algorithm complexity, originality, or general educational effectiveness. Broader device/accessibility checks and trials with real beginners are the next milestone.

The language runtimes require their CDNs and an HTTP server. The HTML snapshot can preview lessons and games, but code execution uses the Vite server and bundled worker assets. Backend, accounts, AI tutoring, remote analytics, and additional curriculum remain deferred.
