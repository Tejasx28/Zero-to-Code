## Practical limits

This verifies behavior and presentation, not educational effectiveness. No two-day human retention experiment has occurred; the 48-hour eligibility boundary is covered by state tests. Concept snapshots are prototype measures. Output tests do not prove which algorithm was used, complexity, originality, or independent mastery by themselves. Use the self-test protocol and the learner's explanation to evaluate the teaching.

The browser runtimes need internet for downloads and a local HTTP server. Python replay records at most 180 events per case. Java currently offers compiler diagnostics and input/output evidence, without variable replay. Backend, accounts, AI tutoring, analytics, and a full curriculum remain deferred.
