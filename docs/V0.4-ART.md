## Active visual direction

The welcome card uses the original portrait. Small guide avatars use the four-expression sheet. Keep the face legible and allow the editor to dominate the page. Pair reactions with useful text and accessible expression labels; the emotion should not be the only feedback.

The interface uses forest green, sand beige, and contrasting coral orange accents. The Geass-inspired symbol is a code-native SVG in `src/CCGuide.tsx`; it is separate from these generated raster assets. The earlier `command-academy.png` poster asset is retained in project history but is not rendered as the active hero.

For the final project, the assets live under `public/art/`. The longer `work/dsa-quest-v0.4/` paths above record the staging locations used when creating them. The original generation files are preserved. No application source was modified as part of asset creation.
