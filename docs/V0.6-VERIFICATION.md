## Technical and learning limits

The application now uses real URLs and client-side React routing. It is not a rewrite into independently server-rendered HTML pages. Vite serves direct paths locally; production hosting needs an index.html fallback. A standard _redirects file is included for compatible hosts. The current base assumes domain-root hosting.

The main application/editor bundle is about 908 kB before compression (295 kB gzip), so Vite reports a bundle-size warning. Debug Lab itself is lazy-loaded. Further editor code splitting can be considered separately. No build error occurred.

First browser-runtime downloads need internet. Python traces keep at most 180 events per test; Java variable replay is not implemented. C.C. uses authored guidance and actual run evidence, not an LLM. The single HTML file previews lessons; use the local server for the full app. Testing establishes working behavior and authored fixtures, not improved learning outcomes. No formal accessibility audit or public deployment was performed.
