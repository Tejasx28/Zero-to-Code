## Practical limits

This verifies software behavior and authored examples, not improved learning outcomes. The creator still needs to try a fresh coding task without help and repeat it later.

Spacing previews prove that Python can parse a whitespace candidate. They cannot prove intended block meaning or algorithm correctness. The user reviews and applies a preview, and the app records assistance. Smaller-input searches test at most 24 candidates and do not guarantee the smallest possible failure. They are disabled for independent tasks and do not grade progress.

First Python/Java browser-runtime downloads need internet. Python traces retain at most 180 events; Java variable replay is unavailable. C.C. is authored guidance, not LLM chat. The main JS bundle is about 978 kB before compression (314 kB gzip); Vite reports a size warning, with no build error. Further splitting can be considered separately. No public deployment or formal accessibility audit was performed.
