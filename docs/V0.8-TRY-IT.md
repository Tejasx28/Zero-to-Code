## A useful first session

1. Open **Games → Black Knights Cargo**. Load a crate, try one that no longer fits, and notice that a skipped crate leaves capacity unchanged. Finish the belt.
2. Choose **Program my rule**. Your played example joins the other test inputs. Write a function. If the blank page blocks you, use **Give me a starting frame**. The frame sets up a loop without supplying the decisions.
3. Open C.C. → **Code words** (her default view). Choose **Visit every item**. Read the meanings of `for`, the item name, and the array. Add the construct. It goes into your real program; Ctrl+Z undoes it. Choose a condition or update next. You decide the rule.
4. Under **Choose a different tool**, try **Try one change**. Save an input and actual observation. Edit a relevant instruction, then rerun the same input. No written explanation is needed. Run the full tests after the experiment.
5. With Python, try **Watch one value**. Select `remaining`, pin a moment, and jump to its next change. Read its actual values beside the executed instruction. The editor's **Read line** button explains its current line in short terms.
6. After the program passes, open **Write the remix**. The new task returns remaining capacity, rather than the loaded row. Start fresh and work out what should change. The remix has no solution hints.

## Try a short lesson

Open **Learn → Arrays**. Flip the first card to its code side. Tap `[0]` to see what it means. Step the animation, then use **Write with C.C.** to open a related coding problem. Lesson cards save your place, not a mastery score. The dock always gives direct access to Home, Games, Learn, Code, Practice, and Repair.

## Try the other mechanics

- **Courier:** pilot with arrows or arrow keys on the focused map. Collect cells 15, 29, and 20, finishing at 20. Your moves become input; your function must record every landing, including rejected moves. Map cells use `y * 7 + x`.
- **Vault:** select two key slots to swap. Reverse the row within half its length in swaps. Undo is always available; there is no speed penalty.
- **Signal:** select the first and final indexes of a positive chain. A chain cannot cross zero or a negative value. Keep the earlier chain on a tie.
- **Arena:** read one drone's real code. Enter a test input and the correct expected index. An input the drone gets right earns no victory. Find a separating case, run it, then repair the actual program against varied cases.

Python/Java is always in the header. Drafts, played examples, duel wins, game checks, experiments, and practice records are saved separately by language. Switching languages does not copy code or unlocks. Notes remain in the footer and C.C. help.

C.C. explains concepts and code words without requiring students to explain them back. Her suggestions are authored; run evidence is real. Code passes and engagement are not proof of learning. Close help and try another related function later to test what stayed with you.
