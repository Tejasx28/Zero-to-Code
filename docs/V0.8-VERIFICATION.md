## Practical limits

The first Python/Java runtime download needs internet. Java has real compilation and return evidence, but no variable-snapshot recorder. Python records a bounded trace. C.C. is an authored guide. A static host needs a fallback to `index.html` for direct application URLs.

The production build reports a roughly 1 MB main JavaScript chunk (325 KB compressed). This is a size warning, not a failed build; further splitting remains a performance improvement.

These checks establish implementation behavior, not learning gains. The next learning trial should test whether a beginner can write a related function later with less help. Opening a card, completing a manual game, or passing finite tests is not proof of mastery.
