# DSA Quest v0.9 — field link and expanded training

Run in PROJECT1 with `npm run dev`. Run `npm test` and `npm run build` to check it. The first Python/Java execution needs internet. Existing saves, drafts, notes, and language-specific progress remain compatible.

## Start here

1. Open Games → Sakuradite Reactor. Zero introduces the rule in three short screens. Use Next/Back, Close, or Escape. Mission briefing reopens it anytime. Briefings are remembered per game on this device.
2. Rehearse the running state, then open Program. Write your code freely in Python or Java.
3. For a useful repair trial, enter this Python draft:

```python
def solve(values):
    total = 0
    for n in values:
        total += value
        result.append(total)
    return result
```

4. Run the game tests. Open Scan & repair. C.C. explains that `value` does not match the loop name `n`, and `result` needs a list before it can collect anything.
5. Choose Review supported fixes together. Inspect the before/after program, apply the reviewed patch, then run the full tests. This authored example passes all six cases after the repair. Other programs may need additional algorithm changes. Ctrl+Z undoes an editor patch.
6. Open C.C.'s command hub. Boundary radar runs an individual real test without changing the task score. Branch & rewind saves a draft, shows the saved program, and restores it after an experiment. Restoration does not restore a current test result.
7. Starting structure previews a whole editable setup/loop/return frame in one action. It replaces the draft only when selected. Save a checkpoint first; undo can also restore the earlier text. Frames remain disabled for independent tasks. Generic code-word guidance stays available as an optional tool.

## Companion interaction

C.C. now opens as a floating field link with an animated command hub. Drag the heading on desktop, or use Move link left/right. It is bounded to the viewport. On phones it becomes a scrolling sheet above navigation. Existing emotional reactions, greeting, calm mode, real Python variable records, line explanations, experiments, and error/spacing tools remain available. No learner-written explanation is required.

The clinic is a bounded local pattern checker, not an AI repair engine or complete Python parser. It supports Python missing-name patterns, clear loop-name mismatches, a missing result list used by append, and warnings about resetting state. Ambiguous findings explain a next step instead of inventing a patch. Java uses actual compiler/test evidence; arbitrary Java rewrites are not offered. Passing the current finite cases is not proof of correctness on every possible input or of mastery.

## New games

- Avalon Rescue Stack: process interleaved arrivals/departures, guard empty launches, and preserve last-in-first-out state.
- Resistance Dispatch: process the same style of orders using first-in-first-out service, then return dispatched IDs.
- Zero's Frequency Intercept: probe the middle of a sorted interval; discard the impossible half and find the target index.
- Sakuradite Reactor: keep a running balance across positive and negative readings and record every prefix total.
- Knightmare Sorting Rail: repair adjacent inversions with a seven-swap budget, then write a sorting controller that also preserves duplicates.

Each new world has six authored Python/Java test cases and a related coding contract. There are ten games and 29 practice problems in total. The original games also have Zero's replayable briefings. Their former rule cards now show a compact implementation lens.

## Ten added topic introductions

Stacks, queues, binary search, prefix sums, sliding windows, frequency counts, linear search, two pointers, sorting, and counting work. Together with the original six, Learn has 16 topics. Each new topic includes a topic-specific, step-through worked example alongside its code-word card and related drill; they do not represent a complete advanced curriculum.
